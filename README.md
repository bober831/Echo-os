# EchoOS

Лёгкая операционная система в стиле Windows на базе Alpine Linux. Быстро запускается, мало
занимает и настраивается под себя: панель с кнопкой «Пуск», ярлыки на рабочем столе,
привычные горячие клавиши и готовые стили оформления.

## Что внутри

- Лёгкий рабочий стол: плавающая панель с кнопкой «Пуск», значки быстрого запуска, список окон, трей и часы
- Красивое меню «Пуск» со списком всех программ и поиском (просто начните печатать)
- 8 готовых тем (4 тёмных, 4 светлых), скруглённые углы, обои в цвет темы
- Проводник, терминал, приложение **Параметры EchoOS**
- Русская и английская раскладки (Alt+Shift), установка программ одной кнопкой

## Как получить ISO

1. Откройте на GitHub вкладку **Releases** этого репозитория.
2. Скачайте файл под ваш компьютер:
   - `EchoOS-aarch64.iso` — Mac с чипом Apple (M1, M2, M3, M4…), телефоны и планшеты с ARM
   - `EchoOS-x86_64.iso` — обычные ПК и ноутбуки на Intel или AMD

Если в Releases пусто, откройте **Actions → Build EchoOS ISO → Run workflow** и подождите
15–25 минут: готовый образ появится в Releases.

## Как запустить

### В UTM (Mac, iPhone, iPad)

1. Создайте новую виртуальную машину, тип **Linux**, и выберите скачанный ISO.
2. Память: **не меньше 2 ГБ**, лучше 3–4 ГБ. Система целиком работает из оперативной памяти.
3. Процессоры: 2 ядра.
4. Диск можно создать маленьким (8 ГБ), он нужен только при установке.
5. Запустите машину. Если на экране сначала чёрный экран, подождите: на эмуляции без
   ускорения (UTM SE) первая загрузка идёт дольше.

### В VirtualBox, VMware, QEMU

Создайте машину «Linux / Other Linux (64-bit)», подключите ISO как оптический диск,
выделите не меньше 2 ГБ памяти.

### На обычном компьютере

Запишите ISO на флешку программой Rufus, balenaEtcher или командой `dd` и загрузитесь с неё.
Работает только `x86_64`-образ на обычных ПК.

## Первый вход

Вход выполняется автоматически.

| Что | Значение |
|---|---|
| Пользователь | `user` |
| Пароль | `echo` |

При первом входе откроется окно параметров. Выберите тему или закройте окно и
настройте всё позже: **Пуск → Параметры EchoOS**.

> Это live-система: всё, что вы меняете, хранится в памяти и пропадёт после выключения.
> Чтобы настройки и программы сохранялись, установите EchoOS на диск (раздел ниже).

## Настройка внешнего вида

Откройте **Пуск → Параметры EchoOS** (или Win+I). Всё применяется сразу.

| Вкладка | Что можно менять |
|---|---|
| Темы | 8 тем (Полночь, Графит, Лес, Океан, День, Закат, Роза, Мята), свой цвет выделения |
| Панель и окна | Сверху или снизу, плавающая или на всю ширину, высота, значки, скругление, шрифт, надпись «Пуск», кнопки окон справа или слева, что показывать |
| Обои | Обои из комплекта или своя картинка |
| Система | Раскладки клавиатуры, часовой пояс |
| Программы | Установка браузеров и других приложений |

**Тонкая настройка вручную.** Все параметры лежат в одном файле `~/.config/echoos/shell.conf`
(пишите только то, что хотите изменить). Полный список параметров с пояснениями:
`/usr/share/echoos/defaults.conf`. После правки выполните `echoos-theme apply --reload`.
Например, `PANEL_SIZE=52`, `RADIUS=20`, `PINNED="pcmanfm-qt qterminal falkon"`.
Свою тему сделайте копией любого файла из `/usr/share/echoos/themes/` (цвета BG, BG2, FG, ACCENT…).
Кнопка **Сбросить всё** возвращает стандартный вид.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Win+E | Проводник |
| Win+R | Запуск программы |
| Win+T | Терминал |
| Win+I | Параметры EchoOS |
| Win+D | Показать рабочий стол |
| Win (одна) | Меню «Пуск» |
| Win+←/→ | Окно на половину экрана |
| Ctrl+Shift+Esc | Диспетчер задач |
| Print | Снимок экрана |
| Alt+Shift | Сменить раскладку |

Если в виртуальной машине Win перехватывается основной системой, используйте
меню «Пуск» мышью.

## Установка программ

Нужно подключение к интернету (в виртуальной машине оно обычно есть сразу).

**Через окно:** Параметры EchoOS → вкладка **Программы** → «Установить». Там есть браузеры
(Falkon, Firefox, Chromium), просмотр картинок и PDF, архиватор, калькулятор,
видеоплеер, менеджер паролей, иконки Papirus и шрифты Noto. Для установки попросят пароль
администратора (`echo`).

**Через терминал:**

    sudo apk update
    sudo apk add имя-пакета

Поиск пакета: `apk search слово`.

Браузер по умолчанию изначально лёгкий (Dillo, без JavaScript), потому что тяжёлые браузеры
занимают сотни мегабайт памяти. Если нужен обычный браузер, поставьте его из вкладки
«Программы» и откройте его из меню «Пуск».

## Установка на диск

Live-режим удобен, чтобы попробовать. Для постоянной работы установите систему на диск:

1. Установите обычный Alpine Linux на диск командой `setup-alpine` (подробности на
   [alpinelinux.org](https://alpinelinux.org/downloads/)).
2. После перезагрузки в новую систему выполните от root:

        apk add git
        git clone https://github.com/bober831/Echo-os echoos
        cd echoos
        sh echoos-setup.sh

Скрипт поставит рабочий стол, создаст пользователя, включит нужные службы и перезагрузит
компьютер. Система на диске загружается быстрее, а настройки сохраняются.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Долго загружается | Выделите больше памяти (3–4 ГБ). В UTM без ускорения первая загрузка медленнее, это нормально |
| Загрузка останавливается | Увеличьте память виртуальной машины и запустите заново. Сфотографируйте последний экран и создайте обращение во вкладке Issues |
| Чёрный экран после заставки | Подождите минуту. Если не помогло, перезапустите машину и смените в UTM видеоустройство (virtio-gpu или другое) |
| Нет сети | Подождите 10–20 секунд после входа. В UTM выберите сеть «Общая» (Shared) |
| Не работает Win+... | Используйте «Пуск» мышью, Win может перехватываться основной системой |
| Не хватает места или памяти при установке программы | Установите EchoOS на диск или поставьте меньше программ |
| Забыли пароль | В live-режиме: `user` / `echo` |

## Для разработчиков

- `overlay/` — файлы, попадающие в систему: настройки, init-скрипт, приложение, обои
- `iso/` — профиль сборки, список пакетов `packages.txt`, генератор заставки и обоев, `build.sh`
- `echoos-setup.sh` — установка поверх Alpine
- `.github/workflows/build-iso.yml` — сборка ISO на GitHub Actions

Список пакетов правится в `iso/packages.txt`: `имя` — обязательный, `имя?` — необязательный,
`а|б` — первый существующий. Чем короче список, тем быстрее запускается live-образ.
